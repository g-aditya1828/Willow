# Willow - Frontend(progress)

WEEK - 1 (WEBSITE)

This version uses the information architecture and consumer-first transparency direction described in the supplied Willow specification, with a playful sticker/illustration visual language inspired by the reference style.

It includes:

- Hero / product introduction
- How Willow works
- India-first local/unbranded food section
- 0–100 Willow score
- Product photo upload demo
- Better alternatives
- Independence / no-ads section
- Scientific sources section
- Responsive layout

The current scanner is a front-end demo. Connect the upload handler to your OCR, ingredient normalization, nutrition analysis and scoring API for real results.

The specification defines Nutrition 60%, Additives 30%, Clean/Organic 10%, and photo OCR without requiring a barcode.
